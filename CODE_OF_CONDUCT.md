# Code of Conduct

Lucy AIOS welcomes rigorous technical disagreement.

Participants are expected to:

- discuss ideas, evidence, architecture, and behavior rather than attacking people
- distinguish reproduced facts from assumptions
- avoid harassment, threats, discrimination, or doxxing
- avoid publishing sensitive security exploits before responsible disclosure
- respect licensing and confidentiality boundaries

Good criticism makes the project stronger.

Repeated abusive behavior may result in removal from project spaces.
