## What success looks like

Success is not measured only by stars.

Useful signals include:

- independent reproduction
- serious architecture criticism
- security findings
- verifier contributions
- integrations
- discussions that produce design changes
- pilot interest
- long-term contributors

The public roadmap is successful when an outside reviewer can tell the difference between what Lucy intends to become and what the project can currently prove.
